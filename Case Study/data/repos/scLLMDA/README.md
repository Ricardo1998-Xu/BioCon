# 📌 scLLMDA

**scLLMDA** is a Python-based project (version **3.8.20**) implementing the `scLLMDA` model. The core functionalities are organized under the `scLLMDA/` and `gda/` directories.  
To run the project, simply execute the `main.ipynb` notebook after setting up the environment.

---


## 🛠 Environment Setup

It is recommended to use a virtual environment to isolate project dependencies. Follow the steps below to create and activate the environment:

```bash
# Create a Python 3.8.20 virtual environment named scLLMDA
conda create -n scLLMDA python=3.8.20

# Activate the virtual environment
conda activate scLLMDA

# Install dependencies
pip install -r requirement.txt
